# Android and Solana Mobile release 7 — 13 October 2026

Version **0.1.0 (7)** updates the Android and Solana Mobile client with the latest
notification and achievement stability fixes while retaining wallet deposits,
withdrawal destination verification and Android navigation fixes.

## Changes

- Notification permission and Settings failures remain retryable and no longer
  incorrectly appear as permission denial or successful registration.
- Achievement grids use static native images and virtualized rows. Optional shine
  effects are limited to an opened earned coin; locked details show requirements.
- Achievement details scroll within bounded image layouts, with updated coin art,
  progress and leaderboard presentation.
- Release builds reject missing authentication configuration.

## Release boundaries

This is the live mainnet Android build. The public source defaults to local sample
mode; sample balances and transactions are simulated. Physical-device notification
delivery and wallet deposit/withdrawal acceptance remain separate checks. Matching
hosted account services are required for live features. Publishing this snapshot
and downloadable artifacts does not deploy backend services or submit to Google
Play or the Solana dApp Store. The iOS TestFlight invitation remains in the README;
iOS archive 68 has not been confirmed available to testers by this release.
