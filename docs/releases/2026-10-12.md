# Android and Solana Mobile snapshot — 12 October 2026

This client snapshot includes iOS release 65 parity, Android fixes and the Solana
Mobile build-5 client. It is a source submission, not a backend release.

## Included client updates

- Android Mobile Wallet Adapter USDC deposits into the existing Privy account
  wallet, with recovery of pending transfers and explicit finality checks.
- Android wallet ownership proof when choosing a withdrawal destination; manual
  destination entry remains available. This requires matching service endpoints.
- Android animation decoding/artwork, sheet headers and scrolling, hardware back,
  adaptive launcher icon and device-biometric handling.
- Onboarding resume, clearer bank connection confirmation and refresh feedback,
  notification opt-in handling and separate favourite/fallback stock cards.
- Achievement coins, progress views and leaderboard updates, with shared API types
  and local sample fixtures. Live availability depends on service rollout.

## Readiness

The signed binary is available for direct installation. Physical Android/Solana
Mobile wallet deposit and withdrawal acceptance is still pending. Matching account
service features must be deployed for achievements and destination verification.
Website wallet association and dApp Store publication remain separate release
steps. No store approval, physical-wallet success or complete live end-to-end
validation is claimed by this snapshot.

The source can be evaluated without credentials in mock mode. Sample balances,
funding and withdrawals are simulated and never prove an on-chain transfer.

## Private service updates

The hosted product has also received bank refresh, pending-payment, connection-day
purchase and currency-handling fixes. This snapshot conveys those product changes
without publishing bank-sync rules, execution code, migrations, deployment
records, customer evidence or provider credentials. See [architecture](../architecture.md).

public-only dependency lockfile installs with `--frozen-lockfile`. Privacy checks
exclude private workspaces, infrastructure identifiers, signing files and local

matches the verified local release artifact. These checks do not replace the
