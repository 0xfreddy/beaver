# Company marks

Bundled PNGs for the sample market registry and the purchasable xStocks catalogue. Assets render offline through React Native Image. A dark neutral backplate keeps the artwork legible in both app appearances. Unknown merchants retain an initial; category mapping never changes a merchant's displayed identity.

Source: [NVSTly's public ticker-logo collection](https://github.com/nvstly/icons), revision `3ba2624c7776761af53c8b9f0569173e696f7786`, `ticker_icons/{SBUX,AAPL,AMZN,UBER,NFLX,CMG}.png` retrieved 9 September 2026 and `ticker_icons/{GOOGL,META,MSFT,NVDA,TSLA}.png` retrieved 21 September 2026. Original files are retained without alteration. The collection includes adapted logos; these marks are used only to identify the companies in the sample. Company trademarks and artwork remain the property of their respective owners and are not relicensed by this repository.

## Bank marks

The ten `banks/*.png` marks identify popular US banks in the connection carousel and serve as offline fallbacks for matching connected banks. Retrieved from Logo.dev's domain image API on 23 September 2026 at 256 px. Domain filenames preserve the source identity; no API key is bundled. Bank trademarks remain their owners' property.
