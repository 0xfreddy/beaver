# Receipt currency illustrations

Six transparent PNG assets generated on 2026-10-11 from the existing wallet-token.png visual reference using the image generation tool. Each keeps the brushed-silver wallet/coin material and embosses its ISO currency code. GBP is the requested British currency (the request said GB).

Original generated assets are retained in the user's Codex generated_images directory. Currency text and selection state are rendered as accessible native UI, not inferred from the artwork.
