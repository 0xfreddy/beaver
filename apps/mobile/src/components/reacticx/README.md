# Reacticx local fork

These components are adapted from Reacticx 1.24.1 at commit
`58479704f1f831913970aa5e78e3691bcb9fa3f7` for Roundups' Expo SDK 57 stack.

The fork deliberately uses the app's theme, SF Symbols, accessibility semantics,
Reduce Motion behavior, and financial navigation rules. Update it manually after
reviewing upstream diffs; it is not wired to overwrite local changes.

Upstream: https://github.com/rit3zh/reacticx
